# Python Scripts Directory
This directory contains the Python files for trace generation, cache simulation, and stimulus conversion.
- `generate_synthetic_moe_trace.py`: Synthetic trace and hint trace generator.
- `expert_cache_sim.py`: Cycle-by-cycle cache simulator with DMA arbitration and duplicate prefetch rules.
- `trace_to_testbench.py`: Converts CSV trace and hint data into Verilog testbench stimulus.
