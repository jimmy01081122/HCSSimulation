# RTL Source Directory
This directory contains the Verilog RTL modules:
- `expert_cache_tag_array.v`: Metadata-only fully associative tag array with prefetched flag tracking.
- `fifo_replacement.v`: FIFO replacement victim way indicator.
- `simple_dma_model.v`: Fixed latency single DMA channel.
- `top_moe_prefetch_system.v`: System integration module.
- `lru_replacement.v`: (Phase B TODO) LRU replacement module.
